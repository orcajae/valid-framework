# Literature audit: withdrawn (October 2026)

The literature-audit coding sheet (`literature_audit_80.csv`), its summary and its analysis script were removed from the current version of this repository. They remain in the git history.

Why: of the 74 rows coded as empirical, 15 match the paper they cite, 41 match a real paper only with a different author, venue, year or method, and 18 match no paper we could find. The sheet was produced by AI-assisted web search without a record of the sources, and was never checked against the papers. The audit statistics and the codes attributed to individual papers are withdrawn. Details: [CHANGELOG_CR.md, E13](../CHANGELOG_CR.md#e13-most-empirical-results-withdrawn-after-a-full-re-verification).

A literature audit will appear here again only if it is rebuilt from a logged search, with every code tied to a quoted passage.
