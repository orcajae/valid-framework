2 Summary

SAMPLE: fictional fund, synthetic data, illustrative only. Findings, no assurance.

Each check was run exactly as the fund defines it, on 200 series in each of four groups. A check should pass rarely when there is no edge (bound for this sample: at most 15 of 200) and often when an edge is planted (bound for this sample: at least 100 of 200).

What the sample shows

  • Each check on its own passed series with no edge more often than the bound set for the sample. The largest excess was for a net Sharpe ratio above zero after choosing the best of the eight configurations: 118 of 200 series with no edge passed it. With no edge in these series, those passes come from chance and from the choice of the best configuration.
  • The permutation check shuffles the labels at random, which breaks the overlap between neighbouring five-day labels. It passed 40 of 200 series with no edge. A version that rotates the labels instead, and so keeps the overlap, passed 14 of 200 (descriptive; no verdict was set for it).
  • PBO below 0.20 passed 29 of 200 series with no edge and 34 of 200 with the stronger planted edge: about as often with the edge as without it. The difference was not tested.
  • Requiring all four checks together passed 6 of 200 series with no edge, but caught the stronger planted edge in 13 of 200.

Recommendations are in section 9.

3 The fund's pipeline and checks

SAMPLE: fictional fund, synthetic data, illustrative only. Findings, no assurance.

As the fictional fund describes it:

  • Strategy. One daily long-or-short position in one asset, set at the close and held for the next day.
  • Features. Trailing 5, 20 and 60-day return sums, and a persistent "flow" feature x.
  • Label. Whether the sum of the next five daily moves is positive. Labels of neighbouring days overlap.
  • Model. L2 logistic regression, refitted every 100 days on all earlier days whose labels end before the test block (a walk-forward with a purge); the initial fit uses the earliest 400 usable days, less those whose labels reach into the test block. About 536 test days per series.
  • Configurations. Eight: two feature sets, two strengths of regularisation, and two trading bands (no position while the predicted probability is close to 0.5).
  • Costs. 18 bp for a round trip in and out.
  • Reported backtest. The configuration with the highest test-period net Sharpe ratio, which is the backtest the fund would show.

4 Rules fixed before the run

SAMPLE: fictional fund, synthetic data, illustrative only. Findings, no assurance.

  • Size. A check's size is within the bound if it passes at most 15 of the 200 series with no edge; otherwise it exceeds the bound. The same rule is reported for the series that keep a drift.
  • Power. A check has adequate power if it passes at least 100 of the 200 series with the stronger planted edge; otherwise its power is weak. Adequate here means at least half; a real review sets the level with the client. The weaker planted edge is reported without a verdict.
  • Exact comparisons. Every rule is decided on integer counts and fractions, and every rate is reported with a 95% Wilson interval.
  • Paired groups. Series j in each group (j from 0 to 199) uses the same random draws, so the groups differ in drift or edge and, for G2 and its rotated version, in the draws used to shuffle or rotate the labels.

These bounds are set for the sample. In a real review they are agreed with the client and written into the pre-registration before the run.

5 Series with no edge

SAMPLE: fictional fund, synthetic data, illustrative only. Findings, no assurance.

Every series comes from a fixed-parameter generator; no market data is read. Daily moves follow a GARCH(1,1) process (daily volatility 0.02, ARCH 0.08, GARCH 0.90) with Student-t innovations (5 degrees of freedom), over 1,000 trading days after a burn-in of 250 days. The flow feature x is an AR(1) series with persistence 0.9, independent of the moves.

  • No edge. No drift, and x has no link to the next day's move.
  • No edge, drift kept. The same, with a daily drift of 0.0005, to show how the checks behave when the asset drifts upward.

A real review builds its no-edge series from the client's own data in more than one way, for example with and without the average move and by resampling blocks of days. This sample uses the synthetic generator alone.

6 Series with a planted edge

SAMPLE: fictional fund, synthetic data, illustrative only. Findings, no assurance.

The planted edge links the flow feature x to the next day's move, with a daily correlation of about 0.04 (weaker) or 0.08 (stronger). Both strengths were set as round values before the run.

The edge works through x, which is one of the fund's own features, so the power measured here is power against an edge the pipeline can see directly. An edge the features do not reach would be harder to catch. A real review names each planted form, because power depends on it.

9 Recommendations

SAMPLE: fictional fund, synthetic data, illustrative only. Findings, no assurance.

For this pipeline and these checks:

  1. Keep the label overlap in the permutation check. Replace random shuffling with a construction that keeps it, such as rotating the labels. In this sample rotation also passed fewer series with the stronger planted edge (40 against 87 of 200), so measure its power as well as its size on the fund's own data before relying on it.
  2. Do not use "net Sharpe ratio above zero" after choosing the best configuration as a pass-or-fail check. With no edge it passed most series. Report it beside the number of configurations tried.
  3. Report PBO as a description of the search, not as a pass-or-fail check. In this sample PBO below 0.20 passed about as many series with the stronger planted edge as series with no edge.
  4. Measure the power of a combined check before requiring it. Requiring all four passed few series with no edge but rarely caught the stronger planted edge. Decide which edge size matters to the fund, then measure power against it.

These recommendations are about the checks. The review does not tune the strategy.

10 Limitations

SAMPLE: fictional fund, synthetic data, illustrative only. Findings, no assurance.

  • Synthetic data from one generator. Size and power depend on the data, and a real review builds its series from the client's data.
  • One pipeline, one grid, one label horizon and one cost rule. Other pipelines, checks, grids, horizons or cost rules can give different rates.
  • The planted edge works through one of the fund's own features. Power against other forms of edge is not measured here.
  • 200 series per group: each rate carries the Wilson interval shown in section 7.
  • The bounds are set for the sample, not agreed with a client.
  • Nothing here shows whether any strategy has an edge in practice.

11 Reproduce it

SAMPLE: fictional fund, synthetic data, illustrative only. Findings, no assurance.

The pre-registration, the run code and the outputs are public in examples/t2_sample. The run reads no data; ours took about 20 seconds with two workers.

git clone https://github.com/orcajae/valid-framework
cd valid-framework/examples/t2_sample
python3 -I -B run.py selftest
python3 -I -B run.py run --out ~/t2_sample_out --workers 2
shasum -a 256 ~/t2_sample_out/rows.csv

The last line should print the rows.csv fingerprint in section 1, and the new decision.json should equal the published one. The run refuses to start if either file differs from its committed version. We reproduced it byte for byte with Python 3.13, numpy 2.5.3, pandas 3.0.5 and scipy 1.18.1; other versions may change rows.csv and, rarely, a selection or a pass, so compare the counts in decision.json.

Where a data licence bars passing data to a third party, the same scripts run in the client's environment; the reviewer receives the output statistics and log hashes but none of the data, and the report says so.
